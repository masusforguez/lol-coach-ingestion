Arquitectura de ingesta y análisis

Tres APIs sintéticas alimentan dos modos de ingesta; los datos aterrizan en Parquet y DuckDB construye vistas analíticas.

La API genera datos sintéticos y su reloj/cuotas viven en memoria. El dashboard funciona localmente y puede consultar Render mediante un proxy de solo lectura; las claves permanecen en el backend. La ingesta persiste Parquet y estado bajo data/ (modo directo: data/lake y data/state; Kafka: data/lake_kafka y data/state_kafka).
